# DSBA 6190 live demonstrations

The live demonstrations from DSBA 6190, Cloud Computing for Data Analysis, at the University of
North Carolina at Charlotte. Each cloud has its own folder, and each folder holds one directory per
demonstration.

| Folder | Cloud |
|---|---|
| [`google/`](google/) | Google Cloud |

Every demonstration runs on the reader's own account and billing. Read the folder's README before
running anything.
